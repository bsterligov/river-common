# river-common

`river-config`: env-only configuration shared by all River Rust services (variables prefixed `RIVER_`).

```toml
river-config = { git = "https://github.com/bsterligov/river-common", tag = "0.1.0" }
```

Releases are tagged automatically from Conventional Commits on `main`.
Specs and agent context live in [river-spec](https://github.com/bsterligov/river-spec).
